## Selected Software Projects

### Autotune

An online pitch correction implementation combining: the phase vocoder for time stretching, sinc resampling, and YIN for pitch detection. I've written [an article](/blog/posts/pitch-shifting/) on this pitch shifting algorithm where I derive it from simple DSP principles. In this project I've packaged it as a plugin for use in DAWs as a demonstration of the algorithm.

### Wave Rendering

Computer graphics is another field I've pursued post graduation. I've enjoyed writing shaders and software abstractions that remove typical boilerplate associated with graphics programming libraries. I've written extensively on one such [ocean wave shader project](/blog/posts/waves/), in which I approximate ocean wave motion and lighting with graphics shaders.

### Text to Speech

Text to speech as a field interested me with its union of audio processing techniques and deep learning application.

My first project here was Hunt and Black's concatenative speech synthesis system. This system uses a large database of phoneme-labelled speech. A cost function is then used to score transitions between phonemes, and Viterbi search applied to minimize this cost function.

[Text to Speech Phoneme DB Github](https://github.com/joelm11/TTS-ConcatenativeSynthesis)

My second project in this field was implementing Tacotron/Tacotron2 TTS deep neural networks. I implemented these networks in Keras and PyTorch. I built data preprocessing and training pipelines, and was able to train these models on an old graphics card. I learned about handling large amounts of data, model architecture, attention implementations and attention alignment difficulties while implementing these models.

[Text to Speech DNN Github](https://github.com/joelm11/tacotron)
